A golden retriever puppy presents a giant sunflower to a beaming robot judge under a "BEST JUDGE EVER!" banner — a warm, joyful image made to make the AI judge happy.

## Run it

```sh
python3 main.py
```

It copies the entry image from the repository to `$MAKEFUN_OUTPUT_DIR/entry.png` (else `/output/entry.png`). Python 3.13, standard library only, no network, deterministic.
